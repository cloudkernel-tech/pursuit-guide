Use Cases
-----------

The Pursuit autopilot is a high-precision positioning, navigation and control system designed for open environments. It provides customized solutions
for agricultural and inspection automation to enhance the accuracy and efficiency of operations.

* **Agriculture automation**:

The Pursuit autopilot can be equipped in agricultural machinery, providing efficient and accurate autonomous navigation solutions for agricultural operations
such as sowing, spraying and harvesting, improving greatly the automation level and production efficiency.

* **Surveillance**:

The Pursuit autopilot can be equipped on surveillance vehicles to improve inspection efficiency, simplify operating procedures, and reduce the need for
human intervention through intelligent path planning and real-time data monitoring.

Key Features
------------------

* **Strong versatility**: Pursuit autopilot can adapt to common wire-controlled chassis on the market, supporting mainstream models such as Ackerman, four-wheel differential, four-wheel drive, and crawler, providing users with more choices.

* **High precision**: Through 4G RTK technology (no base station required), Pursuit autopilot achieves a positioning accuracy of 2cm, and the line patrol accuracy can reach ±0.1m on cement roads, ensuring the accuracy and reliability of the vehicle.

* **Autonomous obstacle avoidance**: Equipped with laser radar, Pursuit autopilot can sense obstacles in real time during global path movement, and complete automatic obstacle avoidance through local path planning to ensure safe driving.

* **Simple interaction**: Pursuit autopilot uses an intuitive touch screen user interface. Users only need to touch the screen and select a waypoint or target area on the map to easily start the task. The user experience is simple and efficient.
