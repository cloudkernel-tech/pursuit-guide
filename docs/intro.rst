Use Cases
-----------

The Pursuit autopilot is a high-precision positioning, navigation and control system designed for open environments. It provides customized solutions
for agricultural and inspection automation to enhance the accuracy and efficiency of operations.

* **Agriculture automation**:

Pursuit autopilot can be equipped in agricultural machinery, providing efficient and accurate autonomous navigation solutions for agricultural operations
such as sowing, spraying and harvesting, improving greatly the automation level and production efficiency.

* **Inspection**:

Pursuit autopilot can be equipped on ground vehicles to improve inspection efficiency, simplify operating procedures, and reduce the need for
human intervention through intelligent path planning and real-time data monitoring.

Key Features
------------------

* **Strong versatility**: Pursuit autopilot supports common AGV chassis from the market, including Ackerman, four-wheel differential drive, and crawler, providing more user options.

* **High precision**: Pursuit autopilot can achieve a positioning accuracy within 2cm with 4G RTK positioning, and the line tracking accuracy can reach ±0.1m on cement roads.

* **Autonomous obstacle avoidance**: Pursuit autopilot can be deployed with an onboard 3D lidar to achieve autonomous obstacle avoidance through local path planning to ensure safe driving.

* **Simple interaction**: Pursuit autopilot adopts an intuitive touch screen user interface. Users only need to touch the screen and define a waypoint mission or target area on the map to start the task.
